Native

Blackbird is a native macOS app, built to feel like something Apple could have shipped.

Fast

Metal renders the terminal at 120 Hz on ProMotion, redrawing only the rows that changed.

Accurate

VT parsing runs on Rust's alacritty_terminal, the same core that powers Alacritty and Zed.

Minimal

There are tabs but no splits, and no profiles, plugins, AI, or config files.

Throughput is measured against Terminal.app, iTerm2, Ghostty, and Alacritty. See benchmarks →

FAQ

ssh says 'xterm-kitty': unknown terminal type.

Blackbird advertises TERM=xterm-kitty so kitty-aware tools get the full keyboard protocol, but older remote hosts don't ship that terminfo entry. Current versions of Blackbird fix this automatically: on the first ssh to a host, shell integration installs the entry remotely (cached per host), and if the remote can't accept it, that connection quietly falls back to TERM=xterm-256color. On older Blackbird versions, run infocmp -x xterm-kitty | ssh <host> 'tic -x -' once per host, or install ncurses-term on the remote. Automatic integration covers zsh and fish; bash users can source the bundled ssh.bash from .bashrc.
